# leuchtkasten-userscripts

Tampermonkey-Userscripts für [leuchtkasten.net](https://www.leuchtkasten.net/).

## leuchtkasten-untermenues.user.js

Ergänzt das Kopfmenü um eine 3. Ebene: Unter „Leuchtkasten Standard“ usw. erscheinen die einzelnen Produkte als Ausklapp-Menü.

**Installieren:** Bei aktivem Tampermonkey diesen Link öffnen – Tampermonkey bietet die Installation an:

https://raw.githubusercontent.com/hpbanitz/leuchtkasten-userscripts/main/leuchtkasten-untermenues.user.js

**Updates:** Tampermonkey prüft automatisch auf neue Versionen (`@updateURL`). Voraussetzung: `@version` wird bei jeder Änderung erhöht.

**Cache leeren:** `?lk3reset` an die Adresse anhängen – die Produktlisten werden dann neu eingelesen (sonst alle 24 h).
